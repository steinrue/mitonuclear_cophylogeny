# Mitonuclear cophylogeny

Code accompanying Hart & Steinrücken (2026): Microevolutionary cophylogeny and its application to mitonuclear
interactions.

The subdirectory [code/](code/) contains all code to compile the data and reproduce the figures from the paper.<br>

The subdirectory [results/single_locus/](results/single_locus/) contains all locus-specific mitonuclear cophylogenetic p-values from samples in the 1000 Genomes Project.
