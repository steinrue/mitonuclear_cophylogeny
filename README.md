# Mitonuclear cophylogeny

Code accompanying Hart & Steinrücken (2026): Microevolutionary cophylogeny reflects host-symbiont population dynamics and human mitonuclear interactions.

The subdirectory [code/](code/) contains all code to compile the data and reproduce the figures from the paper.<br>

## Data availability

Locus-specific p-values of mitonuclear cophylogeny from 1000 Genomes Project data are available [here](https://doi.org/10.5281/zenodo.22679263).
